# data/curated/large-load-tariffs

One record per large-load tariff or statewide rule, built only from orders, tariff sheets, and statutes. Every field cites two independent archived primary sources, or one, labeled "single source", when the second is shown to be unreachable. `verify/gates/curated.mjs` checks each record with `pipeline/lib/curated.mjs`; a field that fails reads "Not public" until it passes. Captures live in `data/curated/captures/large-load/`.
