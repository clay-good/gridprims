# Own implementations

Each module here replaces what would usually be a package. Each has its own tests in `verify/tests/` and is listed with its scope and known limits. The own-implementations gate (`verify/gates/own-implementations.mjs`) fails when a general-purpose module under `parsers/`, `core/lib/`, `verify/lib/`, `site/lib/`, or `pipeline/lib/` has no entry.

| Module | Replaces | Scope | Known limits |
|---|---|---|---|
| `core/lib/precision.mjs` | number-formatting libraries | Significant figures from typed text, rounding, US-style display through `Intl.NumberFormat` | Whole numbers with trailing zeros are read as not significant ("400" carries 1) |
| `verify/lib/walk.mjs` | glob libraries | Recursive file listing and Markdown table reading for the gates | Reads only tables whose first cell is backticked |
| `verify/lib/examples.mjs` | test-vector runners | Runs every manifest's worked examples within their tolerances | Numeric outputs only |
| `parsers/delimited.mjs` | CSV libraries | BOM, UTF-8, UTF-16, and Windows-1252 decoding; comma, tab, semicolon, and pipe detection past preamble lines; RFC 4180 quoting with line breaks in quotes; incremental chunks | No decimal-comma numbers (US exports only); delimiter detection samples the first 50 non-blank lines |
| `parsers/xml.mjs` | XML parsers | Well-formed XML to events or a tree; refuses any DTD, entity declaration, or entity beyond the five predefines; depth limit 256 | Not validating; namespaces are kept as prefixes plus local names, not resolved to URIs; a DTD inside a comment is refused too |
| `parsers/time.mjs` | date and time-zone libraries | IANA zones through `Intl`; wall time to UTC reporting the spring gap and the fall repeat; transition finding to the minute | Results follow the engine's zone data; the cross-engine fixture run waits on the browser driver (task 4.8) |
| `parsers/xlsx.mjs` | spreadsheet and ZIP libraries | ZIP central directory, stored and deflated parts through `DecompressionStream`, shared strings with rich text, inline strings, cached formula values, booleans, errors, date detection from built-in and custom number formats, both date systems, first sheet by workbook order | No ZIP64 (workbooks over 4 GiB), no encryption, no formula evaluation, no external links; serials before 1900-03-01 are off by Excel's phantom leap day |
| `parsers/parquet.mjs` | Apache Arrow, parquet-wasm, hyparquet | Flat Parquet tables: the Thrift compact footer, data pages v1 and v2, PLAIN, dictionary, RLE/bit-packed, delta, and byte-stream-split encodings, Snappy (decoded here), gzip, Brotli, and Zstandard pages, dates and timestamps; checked value for value against pyarrow 26 on fixtures and on 4.9 million rows of PUDL v2026.10.0 (eight tables, every column equal) | Nested columns and LZ4 are refused with a message; reads the whole file into memory; no column statistics or page indexes |
| `verify/lib/zip-writer.mjs` | ZIP writers | Builds `.xlsx` test fixtures and the deterministic MCP release archive: stored or deflated entries, optional data descriptors, no timestamps | No ZIP64 |
| `verify/lib/browser.mjs` | Playwright, Puppeteer, Selenium | Headless Chrome over the DevTools Protocol and Firefox over WebDriver BiDi through Node's `WebSocket`: load a page, evaluate script, record requests, set the viewport, take full-page screenshots; Safari through `safaridriver` for script runs only | No input events or multiple tabs yet; Safari cannot record requests |
| `verify/lib/static-server.mjs` | static file servers | Serves a folder on 127.0.0.1 with content types, plus in-memory routes | Test-only; no range requests or compression |
| `site/lib/html.mjs` | template engines | Tagged-template HTML that escapes every interpolated value unless it is already markup; arrays join; `raw()` for markup this repository wrote | No partials or layouts beyond plain functions |
| `site/lib/i18n.mjs` | message-format libraries | Message lookup by id, `{name}` placeholders, plural forms through `Intl.PluralRules`, dates through `Intl.DateTimeFormat` | No nested select forms yet |
| `verify/lib/contrast.mjs` | color-contrast libraries | WCAG 2.2 relative luminance and contrast ratio for opaque `#rrggbb` colors | No alpha blending; translucent colors must be resolved first |
| `verify/lib/json-schema.mjs` | JSON Schema validators | Checks values against the keywords the published MCP schemas use, for conformance tests | Not a general validator: no `pattern`, `oneOf`, `if`, `$dynamicRef`, or formats |
| `core/lib/load-stats.mjs` | load-analysis libraries | Interval kW, peak and its time, total kWh, load factor over the hours with readings, and monthly peaks in a local zone: the quantities every tool shares | Month grouping looks up each UTC hour once, which assumes zone changes on whole hours (true for US zones) |
| `core/lib/readability.mjs` | readability libraries | Flesch-Kincaid grade with a vowel-group syllable rule and an exceptions list; numbers and unit symbols count as one syllable | English only; checked within 0.5 grade on 21 hand-scored sentences |
| `site/lib/chart.mjs` | charting libraries | SVG line charts with min/max-per-bucket downsampling that keeps every peak, 1-2-5 ticks inside the data range, a labeled highlight point, an accessible summary, and a table view | Lines only so far; no hover crosshair or keyboard point navigation yet; no Canvas heatmaps |
| `verify/lib/requests.mjs` | network-audit helpers | Finds requests that leave our origin and requests carrying a sentinel value | Matches the sentinel with and without its decimal point only |
| `verify/lib/reference-profile.mjs` | performance-testing tools | Applies the reference profile (4x CPU slowdown, 150 ms, 1.6 Mbps down, 750 kbps up) over the DevTools Protocol and states the budgets | Chrome only |
| `core/lib/sha256.mjs` | hashing libraries | Synchronous SHA-256 (FIPS 180-4) for the report proof of work, plus leading-zero-bit counting | Used only where one async platform call per hash would be too slow; checked against the platform on every padding boundary |
| `verify/lib/worker-server.mjs` | local Worker runtimes | Runs the real Worker over Node's HTTP server with a static-asset binding reading `dist/` and in-memory D1 and rate-limit stand-ins | Test-only; implements just the D1 statements the Worker runs |
| `core/lib/shard.mjs` | Parquet and Arrow readers | Reads gridprims column shards (`docs/formats/column-shard.md`): float64 and dictionary-coded text with nulls | Two column types only |
| `pipeline/lib/shard-writer.mjs` | Parquet and Arrow writers | Writes the same format deterministically | Whole shard built in memory |
| `pipeline/lib/registry.mjs` | data-catalog tools | Registry entry rules, recipe step vocabulary, the CEII checklist, and the license matcher that derives mirror, derive, or link | The matcher recognizes only the listed licenses; anything else downgrades |
| `core/lib/lateness.mjs` | release-calendar logic | The one lateness rule: due on the posted date or the cadence, late 30 days after | Cadences: daily, weekly, monthly, quarterly, annual |
| `core/lib/plant-math.mjs` | none (domain arithmetic) | Hours in service by month for a generator that started or retired mid-year, plant capacity factor from prorated nameplate, and short-ton and pound to metric-ton conversion (NIST SP 811 factors); checked against hand-computed fixtures | Proration is by whole months, as EIA reports start and retirement months, not days |
| `core/lib/zip-lookup.mjs` | geocoding and address-lookup services | Reads a typed ZIP (a four-digit entry suggests the dropped leading zero), names the state shards a ZIP's three-digit prefix needs, and matches ZIP to Census ZCTA to counties to the utilities EIA-861 lists, with marketers apart and eGRID subregions, all on the device; checked against 50 cases built from the publishers' files | ZCTAs approximate postal ZIPs; EIA-861 lists territory by county, so every utility in a touched county is returned |
| `core/lib/bill-totals.mjs` | utility bill calculators | Bills from printed totals: entry checks (overlap, duplicate, over 45 days, a likely extra digit, net-metered months), fixed (monthly or daily), minimum, tiered (monthly or daily allowances), and seasonal energy charges priced in exact micro-dollars with day proration across a season change, the comparison with what was paid, the effective price rounded half up to 0.01 cent, and the mid-cycle projection by weekdays or the daily average | Time-of-use energy is priced only from kWh by period; demand charges are not priced from totals; export credits are not modeled |
| `core/lib/urdb-tariff.mjs` | tariff lookup services | URDB residential rates for the bill engine: service (bundled, delivery, delivery with standard offer, energy only), conditions from the rate name (low income, elderly or disabled, EV, space or water heating, all-electric, net metering, farm), whether totals can price it and why not (tiered time of use, a nonzero demand charge, tiers per kW), and the conversion to fixed and minimum charges, named month seasons, tiers with URDB's adjustment added, and time-of-use periods with their hours in words | Conditions are read from the rate name only; monthly fuel adjustments are noted, not applied |
| `core/lib/bill-entry.mjs` | bill-entry forms in utility bill calculators | The written form of billing periods (dates or a month, kWh with thousands separators, kWh by time-of-use period, amount paid, "confirmed") and of tariffs as JSON, read with a reason for every line it cannot read, and the questions the entry checks ask before pricing | One period a line; a month stands for its first to last day |
| `core/lib/usage-benchmark.mjs` | home energy comparison services | EIA-861 residential use per customer for a utility and a state (delivery-only rows left out of state totals, as EIA's Table 5A counts them), a year of use from billing periods or scaled from fewer by days, the percent difference, and the seasonal swing with a checklist of causes to check; state averages match Table 5A in all 51 states | Averages only: EIA-861 publishes no distribution, so no percentiles or rankings |
| `pipeline/lib/licenses.mjs` | license-compliance tools | Chooses each output table's license from its inputs, refuses share-alike and publisher-terms mixes, and carries credits and notices | Knows public domain, CC BY 4.0, CC BY-SA 4.0, ODbL, and publisher terms |
| `pipeline/lib/health.mjs` | status-page tools | Writes the pipeline health record: a row per workflow (interval, threshold, last success, enabled), per dataset (last check, refresh, posture, failure since), the link check, and the last 60 runs | Single writer per run; concurrency groups keep runs from overlapping |
| `pipeline/lib/github.mjs` | the `gh` CLI and Octokit | Re-enables workflows the host disabled for inactivity and opens deduplicated pipeline issues, through `fetch` | Only those two calls |
| `verify/lib/smoke.mjs` | uptime and header checkers | The required-header check and the route list the local Worker test and the post-deploy smoke test share | Status and headers only, not page content |
| `pipeline/lib/terms.mjs` | terms-monitoring tools | Checks that a publisher's recorded terms text still appears on its page, lowers the posture when it does not, and applies takedowns | Exact-text containment after whitespace and quote normalization |
| `verify/lib/reference-vectors.mjs` | test-vector harnesses | Runs stored third-party vectors and checks agreement to every figure the source prints | Single-output tools today |
| `site/lib/redirects.mjs` | redirect matchers | Matches paths against `_redirects` rules with `:placeholder` and `*` segments, and writes the file | No query-string or status-code variants beyond 301 |
| `site/lib/meta.mjs` | SEO and metadata plugins | Fits titles to 60 characters and descriptions to 155 at a word boundary, makes repeated names unique by state and then id, and writes JSON-LD with `<` escaped so no value can close its block | English word boundaries only; a single word longer than the limit is cut mid-word |
| `site/lib/sitemap.mjs` | sitemap generators | XML sitemaps of at most 50,000 URLs under an index, each `lastmod` the date the build gives it, and `robots.txt` | No image, video, or news extensions |
| `site/lib/atom.mjs` | feed libraries | Atom feeds (RFC 4287) with entries newest first and the feed dated by its newest entry, and the data release entry for a dataset version | Summaries are plain text; no `content` element, categories, or enclosures |
| `verify/lib/atom-check.mjs` | feed validators | Checks a feed for what RFC 4287 requires: the namespace, feed and entry ids as absolute IRIs, titles, RFC 3339 dates, an author, a self link, and an alternate link or content per entry | Not a full RELAX NG validation; extension elements are not checked |
| `verify/lib/temp.mjs` | temporary-file libraries | Temporary folders for tests, each removed when its test process exits, so dozens of 300 MB site builds do not fill a CI runner's disk | A process killed by a signal leaves its folders behind |
| `pipeline/lib/curated.mjs` | editorial-review workflows | The curated-fact rules as code: primary sources with stored captures and checksums, two independent archived primaries for disputable fields, refused secondary sources and personal data, recorded conflicts, and the bulk-batch rule | Personal-data patterns are heuristics for US identifiers and addresses |
| `pipeline/lib/ceii.mjs` | compliance review tooling | The CEII screen (18 CFR 388.113) every release runs before it is written: the registry checklist for infrastructure datasets and a check of every published column name for location and network words (coordinates, substations, buses, impedances, points of interconnection); a failing release is not written, and a passing one carries the dated record | Screens column names, not cell values; a precise location hidden under a plain name would pass, so normalizers drop such fields by name |
